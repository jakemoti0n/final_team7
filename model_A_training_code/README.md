# Model A 전체 백업 정리본

`audit_A2_v1.tar.gz`에 들어 있던 서버 `model_A` 작업 폴더의 파일을 로컬에서 A1·A2별로 복사·정리했습니다. 이 폴더는 해당 백업 기준이며, 현재 서버와 실시간 동기화된 사본은 아닙니다.

## 구성

- `A1/`: A1 학습 스크립트와 전체 `recycle_yolo11n_14class_v1` 학습 실행 결과·가중치
- `A2/`: A2 학습 스크립트, 전체 `recycle_yolo11n_14class_A-2` 결과·가중치, 실행 로그, 오류 분석 코드, A2 검수 산출물
- `comparisons/A1_vs_A2/`: A1·A2 비교 결과
- `comparisons/dirty_to_clean/`: 오염→클린 오류 비교 결과
- `shared/`: 작업 노트북과 Jupyter checkpoint·Python 캐시

백업에 있는 파일을 보존하면서 위 분류 폴더를 추가로 만들었습니다. 원래 백업 폴더 트리도 `data/recycle_dataset/notebooks/model_A/` 아래에 그대로 남아 있어 대조할 수 있습니다.

## GitHub 업로드 전 주의

모델 가중치(`*.pt`), 이미지·검수 미리보기, 로그, 노트북 출력과 데이터는 저장소를 크게 만들거나 이용 권한·개인정보 문제가 될 수 있습니다. `.gitignore`는 가중치 및 일부 데이터·생성물을 신규 Git 추적에서 제외합니다. 즉, 파일은 이 폴더에 복사돼 있지만 `git add`로 자동 업로드되지 않을 수 있습니다. 업로드 전에 공개해도 되는 항목을 결정하고, 필요한 파일만 선별하세요. 이미 Git이 추적 중인 파일에는 `.gitignore`만으로 제외되지 않습니다.

코드 실행이나 재학습은 하지 않았습니다. 서버 경로·패키지 버전·A2의 `MuSGD` 지원 여부도 현재 환경에서 검증하지 않았습니다.
