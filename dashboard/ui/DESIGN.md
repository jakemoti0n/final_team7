# 관제 화면 디자인 규칙 (DESIGN.md)

사람과 AI 도구(Google Stitch 등)가 함께 읽는 관제 화면(`dashboard/ui`)의 디자인 기준이다.

- **값의 원본은 [`src/styles/tokens.css`](src/styles/tokens.css) 하나다.** 이 문서의 표는 그 사본이다. 토큰을 바꾸면 이 표도 같은 PR에서 바꾼다.
- 컴포넌트 CSS는 색·글꼴·그림자를 직접 쓰지 않고 `var(--…)`만 쓴다.
- 시안(`dashboard/docs/stitch_autonomous_robot_fleet_control_dashboard/`)은 참고용이다. 생성된 HTML을 붙여 넣지 않고 기존 컴포넌트와 토큰으로 다시 만든다.
- 함께 지킬 동작 규칙: [UX-REQUIREMENTS.md](../docs/UX-REQUIREMENTS.md)

## 1. 원칙

1. **모르는 것은 모른다고 표시한다.** 받지 못한 값은 "—"·"확인 불가"(neutral)로, 마지막 값은 흐리게 + "마지막 수신 값" + 받은 시각.
2. **성공(초록)은 서버가 `confirmed`일 때만.** 클릭·전송·응답만으로 초록을 쓰지 않는다.
3. **색만으로 구분하지 않는다.** 상태마다 기호(● ! ○)와 문구가 다르다.
4. **버튼이 잠긴 이유를 글로 보인다.** `title`(마우스 오버)에만 맡기지 않는다.
5. **로봇이 만들지 않는 숫자를 그리지 않는다.** 시안에 있어도 적재량·배터리 %·E-STOP·"SYSTEM READY" 같은 고정 문구는 쓰지 않는다(분석: 1단계 범위 밖 C·D 항목).

## 2. 글꼴

| 토큰 | 값 | 용도 |
|---|---|---|
| `--font-body` | Pretendard Variable → 시스템 글꼴 | 본문·라벨·버튼·표 |
| `--font-heading` | Gmarket Sans(700·500) → 본문 글꼴 | 화면 제목·카드 제목 |
| `--font-mono` | JetBrains Mono(600·700) | 속도·좌표·시각·요청 ID 같은 숫자 |

모두 빌드에 포함한다(외부 CDN 없음). Pretendard는 글자 묶음별 파일이라 화면에 쓰인 묶음만 받는다. Gmarket Sans는 한글 2,350자로 줄인 파일이다([src/assets/fonts/README.md](src/assets/fonts/README.md)).

## 3. 토큰 (현재 값)

Stitch 시안(`autonomous_metric_control/DESIGN.md`)의 값을 따른다. 시안 색을 **글자**로 쓸 때 바탕과의 대비가 4.5:1에 못 미치면 같은 계열의 더 진한 값으로 바꿨다(경고 `#D97706` → `#92400E`, 링크 `#16A34A` → `#15803D`).

| 묶음 | 토큰 | 값 | 용도 |
|---|---|---|---|
| 주 색 | `--color-primary` / `-hover` | `#14532d` / `#166534` | 사이드바 선택, 주행 시작·재개, 주 버튼, 진행 막대 |
| 글자 | `--color-ink` / `--color-text` | `#111827` / `#1f2937` | 제목·강조 / 본문 |
| | `--color-text-muted` / `-faint` | `#4b5563` / `#6b7280` | 보조 설명 / 오래된 값 |
| 바탕 | `--color-bg` / `--color-surface` | `#f7f8f3` / `#fff` | 페이지 / 카드 |
| 선 | `--color-border` / `-strong` | `#e2e8f0` / `#cbd5e1` | 카드 / 버튼·입력 |
| 강조 | `--color-accent` | `#15803d` | 링크·포커스 |
| 위험 | `--color-danger` / `-hover` | `#dc2626` / `#b91c1c` | 주행 정지 버튼 |
| 상태 good | `--color-good-fg` / `-bg` / `-border` | `#166534` / `#dcfce7` / `#bbf7d0` | 연결됨·수신 중·확인된 성공 |
| 상태 warn | `--color-warn-fg` / `-bg` / `-border` | `#92400e` / `#fef3c7` / `#fde68a` | 지연·확인 필요·경로 편집 잠김 |
| 상태 bad | `--color-bad-fg` / `-bg` / `-border` | `#b91c1c` / `#fee2e2` / `#fecaca` | 끊김·실패 |
| 상태 neutral | `--color-neutral-fg` / `-bg` / `-border` | `#4b5563` / `#f3f4f6` / `#e5e7eb` | 확인 불가·확인 전·마지막 상태 |

| 하단 디스플레이 | `--color-display-lime` / `-on-ink-muted` | `#a3e635` / `#cfe3d6` | 진녹 카드 위 상태 점·진행 막대 / 보조 글자 (`/display`만) |
| 그림자 | `--shadow-menu` | `0 4px 12px rgba(17,24,39,.08)` | 떠 있는 메뉴만. 카드에는 그림자 없음 |

전체 목록은 `tokens.css`에 있다.

## 4. 시안에서 가져온 것과 가져오지 않은 것

- **가져옴**: 색, 모서리, 얇은 카드 테두리, 제목 글꼴(Gmarket Sans 500), 작은 카드의 회색 대문자형 라벨, 둥근 배지, 사이드바(아이콘 + 선택 시 초록 바탕), 순찰 진행 막대(순찰 노드가 보낸 `waypoint_index / waypoint_count`), 숫자의 고정폭 글꼴.
- **가져오지 않음**: 적재량·배터리 %·쓰레기 수거 통계(로봇이 만들지 않는 값), E-STOP·"SYSTEM READY"·"4/4 ONLINE" 같은 고정 문구, 1Hz로 깜박이는 상태 점, 어두운 바탕의 지도(운영 지도 그림이 밝은 점유 격자라서).

## 5. 방문자 안내 (`/visitor`)

운영자 화면과 같은 토큰·글꼴을 쓰되 **방문객이 휴대폰으로 한 번에 읽는 화면**이라 규칙을 조금 다르게 둔다.

- 한 열, 최대 폭 720 px, 사이드바 없음, 단추는 안내 약도의 「실제 지도」 하나. 위쪽 띠는 주 색(`--color-primary`) 바탕에 흰 글자
- 글자를 키운다: 운행 대수 22 px(제목 글꼴), 로봇 이름 18 px, 설명 14~16 px
- 지도: 방향 화살표·순찰 경로·목표 지점을 그리지 않고 큰 원만. 지금 위치는 초록 점 + 연한 원(`--color-map-uncertainty-*`), 마지막 위치는 흰 바탕 회색 점선 원. 지도 비율을 지키며 화면 높이의 70%까지
- 상태 배지: 순찰 중(good) · 잠시 멈춤(warn) · 대기 중·상태 확인 중(neutral) · 연결 끊김(bad). 서버에서 받지 못하면 모두 「확인 불가」(neutral)
- 안내 약도(관제 화면 「약도 편집」)가 있으면 가운데 지도가 약도가 된다: 구역 색·아이콘·이름표, 표시점, 또는 올린 그림. 로봇 점은 실제 지도보다 조금 작게(점 2.3%, 연한 원 4%) 그려 이름표를 덜 가린다. 왼쪽 아래 작은 창(폭 30%, 최대 200 px, 흰 바탕·옅은 그림자)은 실제 지도(자동 약도)와 위치, 「실제 지도」 단추로 약도 자리를 덮으며 크게 열린다
- 시안 `visitor_portal`에서 가져오지 않은 것: 적재량(투입 가능·80% 이상), 내 위치와 거리·도보 시간, 수거 호출, 청결 만족도·비콘 정밀도 같은 숫자

## 6. 로봇 하단 디스플레이 (`/display`)

로봇 하단 화면(1920×1080 가로)에 띄우는 키오스크 화면. 근거는 `signage/docs/PRD_로봇_하단_디스플레이_v0.3.md`와 목업 `limbo-display-q1.html`(장면 ①-Q1)이다.

- 1920×1080 한 장을 창에 맞춰 비율을 지키며 줄이고 늘린다(남는 곳은 검게). 커서 숨김, 단추·링크 없음
- 글자: 본문 40 px 이상(13.3인치 화면에서 약 6 mm, PRD v0.3.6), 제목 64 px 이상. DEMO 표시·소리 안내(운영자용)만 예외. 위치 문구는 120 px에서 시작해 길면 96·76·60 px로 줄인다. 한글은 어절 단위로 줄바꿈(`keep-all`)
- 틀: 위 72 px HUD(주 색 바탕, 로고·「LIMBO 실시간 안내」, 상태 점 + 「LIMBO-01 순찰 중 · 14:32」), 아래 40 px 진행 점(순환 칸 수, 한 칸이면 숨김). 서버와 끊기면 HUD는 로봇 이름 없이 「연결 끊김」(로봇이 끊긴 것과 구분)
- 장면 ①: 왼쪽 1/3 큰 QR(440 px, `/visitor` 고정), 오른쪽 위 진녹 상태 카드(「LIMBO-01은 지금」, 「복도에 있어요」, 상태 알약 + 「201 강의실 쪽으로 가는 중」, 진행 막대 「3 / 10 지점」), 아래 행사 안내 3칸(지난·지금·다음, 지금은 good 색과 「지금」 표시)과 한 줄 문구
- 장면 ②: 팜플렛 그림을 화면 전체에(위 72 px는 HUD가 가림), 비율이 다르면 흐린 같은 그림을 바탕에. 오른쪽 아래 작은 QR(300 px, 설명 40 px). 팜플렛을 만들 때 위 72 px와 오른쪽 아래 400×460 px를 비워 둔다
- 장면 ⑤ 환경 피드백: 왼쪽 나무 그림 904 px 정사각형(둥근 모서리, 그림 위에 글자 없음), 오른쪽 위 accent 색 「우리가 함께 키우는 나무」 40 px, 72 px 큰 문구, 40 px 작은 줄(「수거함을 비운 뒤 · AI 확인 20건 중 18건 바르게」, 판정됐을 때만), 부정이면 다음에 할 일 한 줄. 작은 QR은 ②와 같은 화면 자리. 그림은 `src/assets/display/tree-*.webp`(원본 `signage/assets/images/tree_*.png`를 900 px WebP로, 장마다 80~140 KB). 부정 문구에는 「잘못·실패·오염·위험」, 빨간색, 경고 아이콘을 쓰지 않는다. 서버와 끊기면 숫자 없이 초기 나무
- 순환: ① → ② → ① → ⑤ (팜플렛이 없으면 ① → ⑤). 로봇 연결 끊김·대기 중이면 ①에 머문다
- 장면이 바뀔 때 0.6 s 페이드, 같은 장면끼리(①→①)는 그대로. 움직임 줄이기 설정이면 페이드 없음
- 모르는 것은 지어내지 않는다: 구역 밖이면 「행사장을 돌고 있어요」, 오래된 위치는 「마지막으로 확인한 곳: 복도」, 서버와 끊기면 「지금 위치를 확인할 수 없어요」
- 장면 ④ 「LIMBO가 지나갑니다」: 순찰 중 멈춰 있다 출발하면(서버 `moving` false → true) 8 s, 같은 일은 60 s 안에 다시 띄우지 않음. 지금 장면을 어둡게 덮고(`--color-display-scrim`) 가운데 진녹 카드(라임 테두리, 스피커 표시, 104 px 「LIMBO가 지나갑니다」, 44 px 「복도 → 201 강의실 쪽으로 · 길을 조금 비켜 주세요」). 떠 있는 동안 회전은 멈췄다가 이어 간다. 노란 경고판(④-B)은 쓰지 않는다
- 소리: 운영자가 넣은 TTS 파일, 없으면 브라우저 한국어 음성, 둘 다 없으면 소리 없이. 브라우저가 소리를 막고 있으면 오른쪽 위에 「화면을 한 번 누르면 안내 소리가 켜져요」(누르면 사라짐). 하단 화면은 터치가 안 되므로 키오스크는 자동 재생 허용으로 열고, 이 안내가 하단 화면에 뜨면 키오스크 설정 오류
- 데모(`?demo`)는 왼쪽 아래에 「DEMO · 가상 데이터」
