# Dashboard 검증 보고서

검증일: 2026-10-06 (Asia/Seoul). 구현 및 생성 자료는 `dashboard/`에만 작성했다. `limbo/`와 `relay_prog/` 프로그램 코드는 수정하지 않았다. 기존 미추적 파일은 그대로 보존했다.

- FastAPI 공통 v1 수신 계약, 엄격한 검증 및 오류 응답, 세션/순번/종료 세션 처리.
- 단조 시계 기반 Bridge·토픽·motion 판정, 현재 값/보존 값 구분, 활성 문제와 표시 이력을 분리한 100건 알림.
- 즉시/1초 WebSocket 전체 상태, 브라우저당 대기 한 개, HTTP 조회 및 생존 확인.
- React/TypeScript 실제 화면과 독립 Mock 데모, 3단계 요청 ID 기반 제어 상태 머신, 재시작 모달 및 반응형 화면.
- ROS2 없는 가상 송신기, 실제 ROS2/기존 Bridge/브라우저 통합 검증 도구, 고정 의존성과 설치·실행 README.

Python 테스트에서 Starlette의 AnyIO 별칭에 대한 deprecation warning 1건이 출력된다. 테스트 실패는 없다. 테스트 수량에는 아래 실제 ROS2 통합 실행을 포함하지 않았다.

최종 빌드 이후 실제/데모 격리, 브라우저 끊김·복구, 조용히 멈춘 스트림·탭 복귀의 관련 브라우저 회귀 테스트 3개를 다시 실행해 모두 통과했다.

## 실제 Bridge 통합

ROS2 Jazzy/rclpy 테스트 발행자와 **기존 `relay_prog` Bridge 프로그램**을 별도 프로세스로 실행했다. 도메인 91, 임시 서버 포트 및 임시 Bridge YAML을 사용했다. Reliable/Volatile/Keep Last depth 1 발행자와 기존 Best Effort 구독이 연결됐다. 서버에는 ROS2 의존성을 설치하지 않았다.

```text
실제 ROS2 테스트 메시지 → 기존 Bridge → 새 FastAPI → WebSocket → Chrome 렌더링
```

발행 직후부터 브라우저 DOM의 해당 값·이동 상태·마지막 값 배지 확인까지 Python 단조 시계로 측정한 상한값:

| 입력 | 화면 결과 | 브라우저 반영 상한 |
|---|---|---:|
| 선속도 0, 각속도 0 | 0.00 / 정지 상태 | 0.121초 |
| 선속도 0, 각속도 -0.75 | 0.00 / 이동 중 / 회전 중 | 1.011초 |
| 무효 odom NaN | 현재 확인 불가 / 이전 유효 값 배지 | 0.989초 |
| 선속도 3, 각속도 -0.5 | 3.00 / 이동 중 | 1.010초 |

네 경우 모두 2초 미만. 최초 heartbeat에서 네 토픽 미수신 및 motion null을 확인했다. 네 메시지 형식의 수신, 헤더 0 및 음수 헤더, 유효 숫자 복구도 검증했다. Bridge가 제어 명령을 보내거나 기존 로봇 동작을 변경하지 않는다.

관찰 도구는 종료 후 브라우저·Bridge·서버를 정리한다. 측정 원본은 실행 시 `artifacts/bridge-validation.json`, 가상 HTTP 결과는 `artifacts/http-validation.json`에 생성된다.

## 화면 검증

제공된 `LIMBO 운영자 대시보드 목업.zip`의 HTML을 Chrome에서 렌더링하고 1440px 구현 스크린샷과 비교했다. 좌우 56px 여백, 남색 강조선, 두 요약 카드, 약 2:1 본문, 흰 카드·회색 배경·청록 강조를 반영했다. PRD에 맞춰 수신 빈도 열, 실제/데모 분리, 실제 버튼 비활성 안내, 3단계 결과를 추가했다. 목업 전용 `support.js`는 제품에 복사하지 않았다.

1440·1024·768·390px에서 여섯 데모 시나리오와 실제 화면의 수평 넘침 검사가 통과했다. 390px 행 카드와 1440px 실제 수신 화면을 이미지로 직접 확인했다. 모달의 초기 취소 포커스, 양방향 Tab 순환, Esc, 호출 버튼 포커스 복귀를 브라우저에서 확인했다. 외부 폰트 다운로드 없이 시스템 글꼴로 검증했다.

스크린샷은 `artifacts/reference-1440.png`, `bridge-1440.png`, `live-{width}.png`, `demo-{width}.png`에 생성된다. 런타임 생성물은 git에서 제외한다.

## 미검증 및 범위 밖

- 기존 LIMBO Gazebo 전체 주행 스택이나 실물 로봇의 실제 발행 주기/QoS에서의 연결 및 장시간 동작은 미검증이다. 이번 통합 입력은 실제 ROS2 **테스트 발행자**다.
- 장시간 부하·CPU/RSS, 다수 브라우저 동시 연결, 실제 네트워크 대역폭 고갈 및 느린 클라이언트 장기 부하는 미측정이다. 대기 큐 크기 1과 알림/세션 보관 상한은 코드와 자동 테스트로 확인했다.
- Chrome 외 브라우저, 실제 모바일 기기 및 스크린리더 낭독은 미검증이다.
- 실제 원격 정지·순찰 재개·프로세스 재시작은 의도적으로 미구현이다. 데모 성공은 실제 로봇 제어 검증이 아니다.
- 인증, 인터넷 배포, 다중 프로세스 상태 공유, 장기 이력 DB는 범위 밖이다.
