4. Recovery Server (Behavior Server)

← 메인 목록

Recovery Server (ROS 2 Humble 이후 'Behavior Server'로 명칭 확장)는 로봇이 경로 추종 중 **고립되거나, 동적 장애물에 둘러싸이거나, 지도 데이터 오류로 인해 멈췄을 때** 이를 스스로 해결하기 위한 복구 동작을 수행합니다. 독립된 거대한 알고리즘을 사용하기보다는 **코스트맵 초기화, 제자리 회전, 대기, 후진** 등의 단순 명료한 동작(Behavior) 플러그인들을 단계적으로 실행하여 시스템의 자율성과 안정성을 확보합니다.

▲ [Recovery Server] 고립/교착 상태 발생 시 단계별 복구 동작 플러그인(Clear Costmap ➔ Spin ➔ Back Up) 실행
주요 역할 및 특징
  • 단계적 복구 전략: 부드러운 복구(코스트맵 초기화)부터 강한 복구(후진/회전)로 순차적 집행
  • 독립 플러그인 구조: 필요한 복구 동작만 플러그인 형태로 로딩하여 비동기 실행 가능
  • 안전 보장: 후진(Back Up)이나 회전(Spin) 시에도 Local Costmap을 실시간 확인하여 추가 충돌 방지
  • BT Navigator 연동: Behavior Tree XML 상의 RecoveryFallback 노드에 의해 자동으로 호출됨
주요 Recovery (Behavior) 플러그인 종류
플러그인 이름 C++ / Python 지정 클래스 동작 설명 및 활용 목적
ClearCostmapExceptGlobal nav2_behaviors::ClearCostmapBehavior 동적 장애물이 지나갔음에도 코스트맵에 남아있는 유령 잔상(Ghost Obstacle)을 강제로 지움
Spin Behavior nav2_behaviors::SpinBehavior 로봇을 제자리에서 360도 회전시켜 주변 센서 데이터를 재수집하고 새로운 탈출 경로 탐색 도모
BackUp Behavior nav2_behaviors::BackUpBehavior 막다른 길이나 막힌 코너에 도달했을 때 지정된 거리만큼 안전하게 후진 이동
Wait Behavior nav2_behaviors::WaitBehavior 사람이나 이동식 장애물이 통로를 비켜줄 때까지 지정된 시간 동안 제자리에 정지하여 대기
설정 및 코드 예시
📄 nav2_params.yaml (Behavior/Recovery Server 설정 예시)
behavior_server:
  ros__parameters:
    costmap_topic: local_costmap/costmap_raw # 복구 동작 시 실시간 충돌을 감지할 코스트맵 토픽 지정
    footprint_topic: local_costmap/published_footprint # 로봇 외형(Footprint) 영역 토픽 지정
    cycle_frequency: 10.0                    # 복구 행동 제어 연산 주기 (Hz 단위, 초당 10회)
    behavior_plugins: ["spin", "backup", "wait"] # 사용할 복구 플러그인들의 별칭(Alias) 리스트

    # --- 1. Spin (제자리 회전) 플러그인 상세 설정 ---
    spin:
      plugin: "nav2_behaviors::SpinBehavior" # Spin 동작을 수행할 내장 플러그인 지정
      simulate_ahead_time: 2.0               # 회전 전 충돌 예측 시뮬레이션 시간 (초)

    # --- 2. BackUp (후진) 플러그인 상세 설정 ---
    backup:
      plugin: "nav2_behaviors::BackUpBehavior" # BackUp 동작을 수행할 내장 플러그인 지정
      simulate_ahead_time: 2.0                 # 후진 방향 충돌 위험 시뮬레이션 시간 (초)

    # --- 3. Wait (대기) 플러그인 상세 설정 ---
    wait:
      plugin: "nav2_behaviors::WaitBehavior"   # Wait 동작을 수행할 내장 플러그인 지정
💻 Python rclpy Action Client (Spin 직접 호출 예시)
import rclpy                                      # ROS 2 Python 클라이언트 라이브러리 임포트
from rclpy.node import Node                       # ROS 2 노드 클래스 임포트
from rclpy.action import ActionClient             # ROS 2 Action Client 모듈 임포트
from nav2_msgs.action import Spin                  # Nav2 Spin 액션 메시지 타입 임포트

class RecoveryClient(Node):
    def __init__(self):
        super().__init__('recovery_action_client') # 'recovery_action_client'라는 이름의 노드 초기화
        # Recovery Server의 "spin" 액션 서버와 통신할 ActionClient 생성
        self._action_client = ActionClient(self, Spin, 'spin')

    def send_spin_goal(self, target_yaw=1.57):
        # 1. Spin 액션 목표 메시지(Goal) 객체 생성
        goal_msg = Spin.Goal()
        goal_msg.target_yaw = target_yaw            # 회전할 각도 설정 (라디안 단위, 1.57 rad = 약 90도)

        # 2. 액션 서버 연결 상태 확인 및 대기
        self._action_client.wait_for_server()

        # 3. Spin 회전 복구 동작 비동기 요청 전송
        return self._action_client.send_goal_async(goal_msg)

def main(args=None):
    rclpy.init(args=args)                          # ROS 2 Python 통신 시스템 초기화
    recovery_node = RecoveryClient()               # 복구 요청 노드 인스턴스 생성
    recovery_node.send_spin_goal(target_yaw=1.57)  # 시계 반대 방향 90도 회전 요청 실행
    rclpy.spin(recovery_node)                      # 콜백 이벤트 대기 루프 실행

if __name__ == '__main__':
    main()
