2. Controller Server (Local Planner)

← 메인 목록

Controller Server는 Planner Server가 계산한 Global Path를 따라 로봇을 실제로 주행시키는 지역 경로 계획(Local Planner/Trajectory Controller) 모듈입니다. Local Costmap과 센서 데이터를 실시간으로 반영하여 돌발 장애물을 회피하고, 모터 제어 명령인 cmd_vel(선속도, 각속도)을 생성합니다.

▲ [Controller Server] 실시간 센서로 돌발 장애물을 감지하여 회피 궤적 계산 및 모터 명령(cmd_vel) 출력
주요 역할 및 특징
  • Action Interface: nav2_msgs/action/FollowPath 액션 서버를 통해 경로 추종 요청 수신
  • 실시간 장애물 회피: 수십 Hz 단위의 빠른 주기(예: 20Hz)로 로봇의 가속도/속도 제한을 고려한 궤적 계산
  • Goal Checker 모듈: 목표 지점에 도착했는지(거리 오차, 회전각 오차)를 독립적인 크리티컬 모듈로 판단
대표적인 Controller 플러그인
플러그인 명 알고리즘 기반 특징 및 주요 사용처
DWB Local Planner DWA (Dynamic Window Approach) ROS 1의 DWA를 확장 개선한 Nav2 기본 2D 컨트롤러. 여러 평가기(Critic)를 조합 가능
TEB Local Planner Timed Elastic Band 최적화 기반 궤적 생성. 차동 구동, 옴니, 아커만 등 다양한 구동 방식 및 동적 장애물 회피에 강함
MPPI Controller Model Predictive Path Integral GPU/CPU 병렬 연산 기반의 확률적 제어기. 복잡한 지형과 고속 주행 시 뛰어난 제어 성능 제공
Graceful Controller Control Theory (Lyapunov) 연속적인 곡선 주행과 매끄러운 정차 동작이 필요한 실내 서비스 로봇에 적합
설정 및 코드 예시
📄 nav2_params.yaml (Controller Server & DWB 설정 예시)
controller_server:
  ros__parameters:
    use_sim_time: true                     # 시뮬레이션 시간 사용 여부 (Gazebo 등 활용 시 true)
    controller_frequency: 20.0             # 제어 명령(cmd_vel)을 계산하고 발행할 주기 (Hz 단위, 초당 20회)
    min_x_velocity_threshold: 0.001        # X축(전진) 방향 최소 속도 문턱값 (이 값 이하 시 정지 상태로 간주)
    min_y_velocity_threshold: 0.5          # Y축(측면) 방향 최소 속도 문턱값 (옴니휠/메카넘휠 로봇 전용)
    min_theta_velocity_threshold: 0.001    # 제자리 회전(각속도) 최소 문턱값 (rad/s 단위)
    failure_tolerance: 0.3                 # 제어 실패 시 에러를 발생시키기 전 허용할 대기 시간 (초 단위)
    progress_checker_plugin: "progress_checker" # 로봇이 정체되지 않고 실제로 이동 중인지 감시하는 플러그인
    goal_checker_plugins: ["general_goal_checker"] # 목표 지점 도착 여부를 판단할 플러그인 리스트
    controller_plugins: ["FollowPath"]     # 사용할 로컬 컨트롤러 플러그인의 별칭(Alias) 등록

    # --- DWB Local Planner 상세 파라미터 설정 ---
    FollowPath:
      plugin: "dwb_core::DWBLocalPlanner" # DWB 컨트롤러 C++ 플러그인 클래스 지정
      debug_trajectory_details: true      # RViz 시각화를 위해 계산된 궤적의 상세 디버깅 정보 발행 여부
      min_vel_x: 0.0                      # 전진 가능한 최소 속도 (0.0으로 설정 시 후진 금지)
      max_vel_x: 0.26                     # 전진 가능한 최대 속도 (m/s)
      max_vel_theta: 1.0                  # 최대 회전 속도 (rad/s)
      acc_lim_x: 2.5                      # X축 방향 최대 가속도 한계 (m/s²)
      acc_lim_theta: 3.2                  # 회전 방향 최대 각가속도 한계 (rad/s²)
      decel_lim_x: -2.5                   # X축 방향 최대 감속도 한계 (m/s²)
      decel_lim_theta: -3.2               # 회전 방향 최대 각감속도 한계 (rad/s²)
      
      # 궤적 채점 시 사용할 평가 항목(Critics) 조합
      critics: [
        "RotateToGoal",   # 목표 지점에 거의 도착했을 때 목표 방향을 바라보도록 회전 유도
        "Oscillation",    # 제자리에서 좌우로 흔들리는 진동 현상 방지
        "BaseObstacle",   # 장애물과의 충돌 여부 및 위험도 감지
        "GoalAlign",      # 경로의 최종 목표 정렬 상태 평가
        "PathAlign",      # 전체 경로(Global Path) 방향과의 정렬 상태 평가
        "PathDist",       # 전체 경로에서 너무 멀어지지 않도록 이탈 거리 평가
        "GoalDist"        # 최종 목표 지점까지의 남은 거리 평가
      ]
💻 Python rclpy Action Client (FollowPath 호출 예시)
import rclpy                                      # ROS 2 Python 클라이언트 라이브러리 임포트
from rclpy.node import Node                       # ROS 2 노드 클래스 임포트
from rclpy.action import ActionClient             # ROS 2 Action Client 모듈 임포트
from nav2_msgs.action import FollowPath           # Controller Server 경로 추종용 Action 메시지 임포트

class ControllerClient(Node):
def __init__(self):
    super().__init__('controller_action_client') # 'controller_action_client' 이름의 노드 초기화
    # Controller Server의 "follow_path" 액션 서버와 통신할 ActionClient 생성
    self._action_client = ActionClient(self, FollowPath, 'follow_path')

def send_path_to_follow(self, global_path):
    # 1. Controller Server에 전달할 목표 메시지(Goal) 객체 생성
    goal_msg = FollowPath.Goal()

    # 2. Planner에서 전달받은 경로(nav_msgs/Path) 연결
    goal_msg.path = global_path               # 추종할 전체 경로 지정

    # 3. 사용할 컨트롤러 플러그인 별칭 지정 (YAML의 controller_plugins 이름과 일치)
    goal_msg.controller_id = 'FollowPath'

    # 4. 액션 서버 준비 상태 확인 및 대기
    self._action_client.wait_for_server()

    # 5. Controller Server에 경로 추종 비동기 요청 전송
    return self._action_client.send_goal_async(goal_msg)

def main(args=None):
rclpy.init(args=args)                         # ROS 2 Python 통신 시스템 초기화
controller_node = ControllerClient()          # 경로 추종 요청 노드 인스턴스 생성
# controller_node.send_path_to_follow(calculated_path) # 생성된 경로 객체 전달 및 실행
rclpy.spin(controller_node)                    # 콜백 이벤트 대기 루프 실행

if __name__ == '__main__':
main()
