6. Costmap 2D (Global & Local)

← 메인 목록

Costmap 2D는 센서 데이터(LiDAR, Depth Camera 등)와 지도 정보를 종합하여 로봇이 이동할 수 있는 공간과 장애물 영역을 2D 격자 지도 상의 **위험도 점수(Cost, 0~255)**로 수치화하는 서버입니다. Nav2에서는 전체 지도 기반의 경로를 계산하는 Global Costmap과 실시간 장애물 회피를 담당하는 Local Costmap 두 가지를 운영합니다.

▲ [Costmap 2D] 정적 지도 데이터와 실시간 센서 데이터를 가공하여 위험도(Cost) 영역을 생성하는 구조
주요 역할 및 특징
  • 다중 레이어(Multi-layer) 구조: 정적 지도, 실시간 센서, 팽창 영역, 금지 구역 등을 겹쳐서 최종 Cost 계산
  • Global Costmap: 전체 맵 기준, static_layer 위주로 구성하며 Planner Server가 글로벌 경로를 작성할 때 참조
  • Local Costmap: 로봇 중심의 이동형 윈도우(Rolling Window), obstacle_layer 위주로 Controller Server가 사용
  • Inflation (팽창): 로봇의 충돌 반지름(Radius)만큼 장애물 주변에 가상의 위험 영역을 형성하여 충돌 예방
주요 Costmap Layer 플러그인 종류
레이어 이름 지정 클래스 동작 설명 및 활용 목적
Static Layer nav2_costmap_2d::StaticLayer Map Server가 발행하는 정적 지도(Occupancy Grid)를 바탕으로 기본 벽/구조물 코스트 생성
Obstacle Layer nav2_costmap_2d::ObstacleLayer LiDAR/Depth 센서 데이터를 실시간으로 받아 감지된 동적 장애물 지점을 코스트로 반영
Inflation Layer nav2_costmap_2d::InflationLayer 장애물 근처로 갈수록 코스트 값을 점진적으로 증가시켜 로봇이 장애물과 안전 거리를 유지하도록 유도
Keepout Filter nav2_costmap_2d::KeepoutFilter 특정 영역(예: 위험 지역, 사람 통행로 등)을 주행 불가 구역으로 지정할 때 사용
설정 및 코드 예시
📄 nav2_params.yaml (Local & Global Costmap 설정 파라미터)
local_costmap:
  local_costmap:
    ros__parameters:
      update_frequency: 5.0                 # 코스트맵 갱신 주기 (Hz)
      publish_frequency: 2.0                # 시각화 토픽 발행 주기 (Hz)
      global_frame: odom                    # 국소 코스트맵의 기준 좌표계
      robot_base_frame: base_link           # 로봇 본체 좌표계
      rolling_window: true                  # 로봇을 중심으로 코스트맵 창이 함께 이동하도록 설정
      width: 3                              # Local Costmap 가로 크기 (m)
      height: 3                             # Local Costmap 세로 크기 (m)
      resolution: 0.05                      # 1격자당 해상도 (5cm)
      robot_radius: 0.22                    # 원형 로봇의 반지름 (m)
      plugins: ["obstacle_layer", "inflation_layer"] # 사용할 레이어 목록

      # --- Obstacle Layer (실시간 장애물 레이어) 설정 ---
      obstacle_layer:
        plugin: "nav2_costmap_2d::ObstacleLayer"
        enabled: true
        observation_sources: scan           # 센서 소스 별칭
        scan:
          topic: /scan                      # LiDAR 라이다 토픽 이름
          max_obstacle_height: 2.0
          clearing: true                    # 장애물이 사라지면 코스트 지우기 활성화
          marking: true                     # 장애물이 감지되면 코스트 찍기 활성화
          data_type: "LaserScan"

      # --- Inflation Layer (팽창 레이어) 설정 ---
      inflation_layer:
        plugin: "nav2_costmap_2d::InflationLayer"
        cost_scaling_factor: 3.0            # 코스트 감쇄 비율 (값이 클수록 코스트가 급격히 줄어듦)
        inflation_radius: 0.55              # 장애물 주변 팽창 한계 반지름 (m)
💻 Python rclpy Subscriber (Costmap 2D 데이터 수신 및 모니터링 예시)
import rclpy                                      # ROS 2 Python 클라이언트 라이브러리 임포트
from rclpy.node import Node                       # ROS 2 노드 클래스 임포트
from nav_msgs.msg import OccupancyGrid            # Costmap 2D 데이터를 담고 있는 OccupancyGrid 메시지 타입 임포트

class CostmapSubscriber(Node):
    def __init__(self):
        super().__init__('costmap_subscriber_node') # 노드 이름 초기화
        
        # Local Costmap 실시간 격자 지도를 구독(Subscribe)하는 서브스크라이버 생성
        self.subscription = self.create_subscription(
            OccupancyGrid,
            '/local_costmap/costmap_raw',          # Local Costmap 데이터 토픽
            self.costmap_callback,                 # 데이터 수신 시 실행할 콜백 함수
            10                                     # QoS 버퍼 크기
        )

    def costmap_callback(self, msg):
        # 1. Costmap 메타데이터 추출 (해상도, 가로/세로 격자 수)
        resolution = msg.info.resolution          # 격자 1칸당 실측 크기 (m)
        width = msg.info.width                    # 가로 방향 격자 개수
        height = msg.info.height                  # 세로 방향 격자 개수

        # 2. 2D 격자 배열 데이터(0~100 또는 -1) 중 장애물(Cost > 50) 개수 카운트
        obstacle_count = sum(1 for cost in msg.data if cost > 50)

        # 3. 로봇 주변 실시간 장애물 정보 로그 출력
        self.get_logger().info(
            f'[Costmap 수신] 크기: {width}x{height}, 해상도: {resolution}m/cell, 감지된 장애물 Cell 수: {obstacle_count}'
        )

def main(args=None):
    rclpy.init(args=args)                         # ROS 2 Python 통신 시스템 초기화
    costmap_node = CostmapSubscriber()            # Costmap 모니터링 노드 인스턴스 생성
    rclpy.spin(costmap_node)                      # 데이터 수신 대기 루프 실행

if __name__ == '__main__':
    main()
