🚀 팀 프로젝트 Git 워크플로우

우리 팀의 매끄러운 협업과 충돌 방지를 위한 공식 가이드

0. 최초 프로젝트 환경 설정 (딱 한 번만!)

프로젝트를 처음 시작할 때 한 번만 진행하세요.

# 1. 저장소 가져오기
    git clone <저장소_주소>
    cd <저장소_폴더명>

    # 2. dev 브랜치로 이동
    git switch dev

    # 3. 본인 전용 브랜치 및 이동
    git branch <본인_브랜치명>
    git switch <본인_브랜치명>

1. 매일 코딩 시작 전 (최신 상태 동기화)

무작정 작업하면 코드 충돌이 발생할 수 있습니다. 코딩을 시작하기 전 반드시 아래 루틴을 지켜주세요.

# 1. dev 브랜치로 이동
git switch dev

# 2. 최신 코드 받아오기
git pull origin dev

# 3. 내 브랜치로 돌아와서 최신 내용 합치기
git switch <본인_브랜치명>
git merge dev

2. 작업 완료 후 (코드 업로드)

구현이 끝난 코드를 로컬 저장소에 기록하고 원격 서버로 전송합니다.

# 1. 변경된 파일 전체 스테이징
git add .

# 2. 작업 내용 커밋 메시지와 함께 기록
git commit -m "이름 : 작업 내용 요약"

# 3. 내 개인 브랜치로 푸시
git push origin <본인_브랜치명>

3. 깃 관리자에게 검토 요청 (Pull Request)

GitHub 웹사이트에서 본인의 코드를 dev 브랜치로 합쳐달라고 요청합니다.

  • Pull requests 탭 이동 후 New pull request 버튼 클릭
  • Base: dev (기본 설정됨) ⟵ Compare: <본인_브랜치명> 선택
  • 변경 사항 최종 확인 후 하단의 Create pull request 클릭!
