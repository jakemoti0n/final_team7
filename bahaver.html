3. Behavior Tree Navigator

← 메인 목록

Behavior Tree Navigator (BT Navigator)는 Nav2의 전체 자율주행 작업 흐름(Workflow)을 총괄하는 **오케스트레이터(지휘자)** 역할을 담당합니다. 단순히 경로를 계산하고 따라가는 것을 넘어, **"경로 생성 ➔ 경로 추종 ➔ 실패 시 복구 동작(Recovery)"**으로 이어지는 복잡한 내비게이션 논리를 계층 트리 구조(Behavior Tree)로 유연하게 관리합니다.

▲ [Behavior Tree] 주행 성공/실패 여부에 따라 다음 하위 작업(Action)을 유연하게 제어하는 트리 구조
주요 역할 및 특징
  • XML 기반 유연성: C++ 코드 수정 없이 XML 파일 편집만으로 전체 내비게이션 논리 변경 가능
  • 모듈화 및 재사용성: 각 기능(경로 생성, 회종, 복구)이 독립된 노드로 분리되어 손쉬운 재조합 가능
  • 상태 기반 제어: 자식 노드의 반환 값(SUCCESS, FAILURE, RUNNING)을 보고 실시간 조건 제어
  • Groot 시각화 지원: 오픈소스 GUI 도구인 Groot를 통해 실시간 트리 진행 상태 모니터링 가능
Behavior Tree 핵심 노드 유형
노드 종류 (Type) 대표 노드 예시 역할 및 동작 방식
Control Node Sequence, Fallback, Parallel 자식 노드들의 실행 순서를 제어 (예: Sequence는 자식이 모두 성공해야 전체 성공)
Decorator Node RateController, DistanceController 단일 자식 노드의 실행 주기를 제한하거나 실행 조건을 감싸서 변형
Action Node ComputePathToPose, FollowPath, Spin 실제 로봇 동작을 수행하기 위해 ROS 2 Action Server를 호출하는 최하단 Leaf 노드
Condition Node IsStuck, GoalReached 현재 로봇 상태나 조건을 확인하여 True/False 형태의 성공/실패 반환
설정 및 코드 예시
📄 navigate_to_pose_w_replanning_and_recovery.xml (BT XML 예시)
<!-- Behavior Tree 루트 태그 및 사용할 메인 트리 이름 지정 -->
<root main_tree_to_execute="MainTree">
  
  <BehaviorTree ID="MainTree">
    <!-- Fallback: 주행 시도(Sequence)가 실패하면 아래 RecoveryFallback 동작 실행 -->
    <RecoveryFallback>
      
      <!-- PipelineSequence: 경로 재계산과 경로 추종을 병렬/순차적으로 파이프라이닝 -->
      <PipelineSequence name="NavigateWithReplanning">
        
        <!-- RateController: 경로 재계산을 지정한 주기(예: 1Hz, 초당 1회)로 제한 -->
        <RateController hz="1.0">
          <!-- Planner Server 액션을 호출하여 최신 경로 업데이트 -->
          <ComputePathToPose goal="{goal}" path="{path}" planner_id="GridBased"/>
        </RateController>
        
        <!-- Controller Server 액션을 호출하여 업데이트된 경로 추종 -->
        <FollowPath path="{path}" controller_id="FollowPath"/>
        
      </PipelineSequence>

      <!-- 내비게이션 실패 시 실행되는 복구(Recovery) 동작 순서 -->
      <Sequence name="RecoveryActions">
        <!-- 1단계: 코스트맵 장애물 잔상 초기화 -->
        <ClearEntireCostmap service_name="global_costmap/clear_entirely_global_costmap"/>
        <!-- 2단계: 제자리 회전을 통해 고립 탈출 시도 -->
        <Spin spin_dist="1.57"/>
      </Sequence>

    </RecoveryFallback>
  </BehaviorTree>
</root>
💻 Python rclpy Action Client (NavigateToPose 호출 예시)
import rclpy                                      # ROS 2 Python 클라이언트 라이브러리 임포트
from rclpy.node import Node                       # ROS 2 노드 클래스 임포트
from rclpy.action import ActionClient             # ROS 2 Action Client 모듈 임포트
from nav2_msgs.action import NavigateToPose       # BT Navigator 최상위 자율주행 Action 메시지 임포트
from geometry_msgs.msg import PoseStamped         # 위치/방향 정보 생성을 위한 PoseStamped 메시지 임포트

class BTNavigatorClient(Node):
def __init__(self):
    super().__init__('bt_navigator_action_client') # 'bt_navigator_action_client' 이름의 노드 초기화
    # BT Navigator의 "navigate_to_pose" 액션 서버와 통신할 ActionClient 생성
    self._action_client = ActionClient(self, NavigateToPose, 'navigate_to_pose')

def send_nav_goal(self, target_x=5.0, target_y=2.0):
    # 1. BT Navigator에 전달할 목표 메시지(Goal) 객체 생성
    goal_msg = NavigateToPose.Goal()

    # 2. 최종 도달할 목표 위치(PoseStamped) 객체 생성 및 좌표계/좌표 설정
    goal_msg.pose = PoseStamped()
    goal_msg.pose.header.frame_id = 'map'     # 글로벌 지도 좌표계 "map" 기준
    goal_msg.pose.header.stamp = self.get_clock().now().to_msg() # 현재 타임스탬프 저장
    goal_msg.pose.pose.position.x = target_x  # 목표 X 좌표 (m)
    goal_msg.pose.pose.position.y = target_y  # 목표 Y 좌표 (m)

    # 3. 커스텀 BT XML 경로를 지정하고 싶을 경우 사용 (기본 트리 사용 시 생략 가능)
    goal_msg.behavior_tree = 'navigate_to_pose_w_replanning_and_recovery.xml'

    # 4. 액션 서버 준비 상태 확인 및 대기
    self._action_client.wait_for_server()

    # 5. BT Navigator에 전체 내비게이션 수행 비동기 요청 전송
    return self._action_client.send_goal_async(goal_msg)

def main(args=None):
rclpy.init(args=args)                         # ROS 2 Python 통신 시스템 초기화
nav_node = BTNavigatorClient()                # 자율주행 요청 노드 인스턴스 생성
nav_node.send_nav_goal(target_x=5.0, target_y=2.0) # (5.0, 2.0) 위치로 전체 내비게이션 구동
rclpy.spin(nav_node)                          # 콜백 이벤트 대기 루프 실행

if __name__ == '__main__':
main()
