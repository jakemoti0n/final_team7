1-3. 센서 연동 및 Gazebo 플러그인 (LiDAR & IMU)

← 메인 목록

Gazebo 물리 시뮬레이션 환경에 배치된 로봇에 2D LiDAR 센서와 IMU(관성 측정 장치) 플러그인을 결합합니다. 가상 공간의 물체 레이캐스팅(Ray-casting) 및 가속도/각속도 데이터를 생성한 뒤, Gazebo ROS 플러그인(`gazebo_ros_ray_sensor`)을 통해 표준 ROS 2 센서 토픽 메시지(`sensor_msgs/LaserScan`, `sensor_msgs/Imu`)로 변환하여 시각화 도구(RViz2) 및 SLAM/Nav2 노드와 연동합니다.

▲ [그림 1-3] Gazebo 가상 센서 스캐닝부터 ROS 2 토픽 변환 및 RViz2 3D Point Cloud 시각화 처리 파이프라인
주요 역할 및 특징
  • 가상 물리 스캐닝 (Ray-Casting): Gazebo 시뮬레이터 내부의 3D 메쉬 환경과 충돌하는 가상 레이(Ray)를 방사하여 정밀한 거리 데이터 생성
  • ROS 2 표준 메시지 바인딩: Gazebo 내부 C++ 데이터를 sensor_msgs/msg/LaserScan 및 sensor_msgs/msg/Imu 토픽 표준 규격으로 변환
  • 센서 노이즈(Noise) 모델링: 가우시안 노이즈(Gaussian Noise) 파라미터를 추가하여 실제 센서와 유사한 오차 환경 시뮬레이션
  • TF 3D 좌표계 연동: lidar_link, imu_link와 로봇 기준 프레임(`base_link`) 간의 상대적 정적/동적 변환 정보 실시간 유지
센서 플러그인 사양 및 토픽 명세
센서 종류 Gazebo Plugin 파일명 발행 토픽 (Topic) 메시지 타입 (Message Type)
2D LiDAR 센서 libgazebo_ros_ray_sensor.so /scan sensor_msgs/msg/LaserScan
IMU 관성 센서 libgazebo_ros_imu_sensor.so /imu sensor_msgs/msg/Imu
RGB-D 카메라 libgazebo_ros_camera.so /camera/image_raw sensor_msgs/msg/Image

      </geometry>                                     <!-- 형상 종료 -->
      <material name="blue">                          <!-- 파란색 재질 색상 지정 -->

      </material>                                     <!-- 재질 종료 -->
    </visual>                                         <!-- 시각화 설정 종료 -->

  <!-- ================= Gazebo LiDAR 플러그인 바인딩 ================= -->
  <gazebo reference="laser_frame">                    <!-- 플러그인을 적용할 대상 Link를 laser_frame으로 지정 -->
    <sensor name="laser" type="ray">                   <!-- 센서 이름을 laser, 방사형 레이(ray) 타입으로 설정 -->

      <update_rate>10</update_rate>                   <!-- 센서 데이터 업데이트 주기를 10Hz (초당 10회)로 지정 -->

          <horizontal>                                <!-- 수평 평면 2D 스캔 범위를 설정 -->
            <samples>360</samples>                    <!-- 1회 회전당 360개의 레이 샘플 방사 (1도 간격) -->
            <resolution>1</resolution>                 <!-- 해상도 계수 설정 -->
            <min_angle>-3.14</min_angle>              <!-- 최소 스캔 각도 (-180도, -PI rad) -->
            <max_angle>3.14</max_angle>               <!-- 최대 스캔 각도 (+180도, +PI rad) -->
          </horizontal>                               <!-- 수평 스캔 설정 종료 -->
        </scan>                                       <!-- 스캔 설정 종료 -->
        <range>                                       <!-- 센서 측정이 가능한 최소/최대 거리 설정 -->
          <min>0.3</min>                              <!-- 최소 탐지 거리 0.3m (30cm 이내는 무시) -->
          <max>12.0</max>                             <!-- 최대 탐지 거리 12.0m -->
        </range>                                      <!-- 거리 설정 종료 -->
      </ray>                                          <!-- 레이 설정 종료 -->

      <!-- ROS 2 토픽 브릿지 C++ 플러그인 동적 라이브러리 연결 -->
      <plugin name="laser_controller" filename="libgazebo_ros_ray_sensor.so">
        <ros>                                         <!-- ROS 2 설정 구문 시작 -->
          <remapping>~/out:=/scan</remapping>        <!-- 출력 기본 토픽명을 표준 /scan 토픽으로 리매핑 -->

</robot>                                              <!-- Xacro 문서 종료 -->
💻 scan_sub_node.py (ROS 2 센서 수신 검증 파이썬 노드)
import rclpy                                          # ROS 2 파이썬 Client 라이브러리 임포트
from rclpy.node import Node                             # ROS 2 Node 기본 클래스 임포트
from sensor_msgs.msg import LaserScan                 # 레이저 스캔 메시지 타입 임포트

class LidarSubscriberNode(Node):                     # LidarSubscriberNode 클래스 선언
    def __init__(self):
        super().__init__('lidar_subscriber_node')     # 노드 이름을 'lidar_subscriber_node'로 초기화
        
        # /scan 토픽 구독자(Subscriber) 생성 (QoS Depth: 10)
        self.subscription = self.create_subscription(
            LaserScan,                                # 구독할 메시지 타입
            '/scan',                                  # 구독할 토픽 이름
            self.scan_callback,                       # 데이터 수신 시 호출할 콜백 함수
            10                                        # 통신 버퍼 수신 통로 크기(QoS)
        )
        self.get_logger().info('LiDAR 센서 수신 검증 노드가 시작되었습니다.') # 노드 실행 확인 로그 출력

    def scan_callback(self, msg):                    # LiDAR 데이터가 들어올 때 실행되는 콜백 함수
        # 정면 0도 방향의 거리 데이터 추출 (360개 배열 중 중간 인덱스)
        center_index = len(msg.ranges) // 2           # 스캔 배열의 중앙 인덱스 계산
        front_distance = msg.ranges[center_index]     # 정면 방향 측정 거리값(m) 가져오기

        # 터미널 창에 정면 거리 상태 출력
        self.get_logger().info(f'[LiDAR] 정면 장애물 거리: {front_distance:.2f} m')

def main(args=None):                                  # 메인 함수
    rclpy.init(args=args)                             # ROS 2 파이썬 통신 체계 초기화
    node = LidarSubscriberNode()                     # 노드 인스턴스 객체 생성
    
    try:
        rclpy.spin(node)                              # 콜백 함수 반복 수신 루프 대기
    except KeyboardInterrupt:
        pass                                         # Ctrl+C 입력 시 정상 종료 처리
    finally:
        node.destroy_node()                          # 노드 자원 해제
        rclpy.shutdown()                             # ROS 2 파이썬 통신 종료

if __name__ == '__main__':
    main()                                           # 파일 직접 실행 시 main() 함수 호출
