1-1. 3D 가상 월드 구축 (Gazebo World)

← 메인 목록

Gazebo World는 자율주행 시뮬레이션을 수행하기 위해 실세계의 물리적 법칙과 환경 요소를 컴퓨터 환경에 구현한 SDF(Simulation Description Format) 기반의 3D 가상 공간입니다. Open Robotics 및 Gazebo 공식 docs 표준을 준수하여 중력, 조명, 마찰력 및 정적/동적 장애물 특성을 정밀하게 정의합니다.

▲ [그림 1-1] 3D 설계도(.world)가 시뮬레이터 엔진을 거쳐 3D 화면과 ROS 2 자율주행 데이터로 전달되는 전체 흐름
주요 역할 및 특징
  • 물리 엔진 기반 시뮬레이션: ODE(Open Dynamics Engine)를 기본 엔진으로 사용하여 중력($9.8m/s^2$) 및 바닥 접촉 마찰력 연산
  • SDF (Simulation Description Format) 표준: ISO XML 규격을 준수하여 조명(Sun), 바닥(Ground), 장애물(Model) 정밀 배치
  • Building Editor 지원: Gazebo 내장 툴을 활용해 실제 도면 기반 벽체 구조물 및 멀티룸 시나리오 환경 생성
  • 시뮬레이션 시간 동기화: ROS 2 시스템에 /clock 토픽을 제공하여 실제 시간과 시뮬레이션 타임(Sim Time) 동기화
Gazebo World 주요 태그 구성 요소
태그 이름 SDF 설정 예시 기능 및 역할
<physics> type="ode" 시뮬레이션 연산 주기(Step Time, 예: 0.001s) 및 물리 연산 엔진 지정
<light> type="directional" 가상 광원(태양광 등)의 위치, 조사 방향 및 그림자(Shadows) 연산 설정
<include> <uri>model://...</uri> Gazebo Fuel 및 로컬 3D 장애물 모델(벽, 가구, 기둥 등)을 가상 월드로 로드
<plugin> gazebo_ros_factory ROS 2 서비스 및 토픽을 통해 로봇을 동적으로 스폰(Spawn)하고 월드 상태 제어
설정 및 코드 예시
📄 my_custom_world.world (Gazebo 3D World SDF 설정 파라미터)
<sdf version="1.6">                                   <!-- SDF(Simulation Description Format) 버전을 1.6으로 지정 -->
  <world name="default">                              <!-- 기본 월드 노드 생성 및 이름을 'default'로 설정 -->

    <include>                                         <!-- 태양 광원(Light) 모델 정의 시작 -->
      <uri>model://sun</uri>                         <!-- Gazebo 기본 저장소에서 'sun' 모델을 불러와 배치 -->
    </include>                                        <!-- 광원 모델 불러오기 종료 -->

    <include>                                         <!-- 3D 가상 공간의 바닥(Ground) 모델 정의 시작 -->
      <uri>model://ground_plane</uri>                 <!-- 평면 바닥 모델인 'ground_plane'을 불러옴 -->
    </include>                                        <!-- 바닥 모델 불러오기 종료 -->

    <physics type="ode">                              <!-- 물리 엔진 타입을 Open Dynamics Engine(ODE)로 설정 -->
      <max_step_size>0.001</max_step_size>            <!-- 물리 연산 스텝 크기를 0.001초(1ms)로 설정하여 정밀도 확보 -->
      <real_time_factor>1.0</real_time_factor>          <!-- 실제 시간 대비 시뮬레이션 진행 배율을 1.0(동일 속도)으로 지정 -->
      <real_time_update_rate>1000</real_time_update_rate> <!-- 초당 물리 루프 업데이트 횟수를 1000Hz로 설정 -->
    </physics>                                        <!-- 물리 엔진 설정 종료 -->

    <include>                                         <!-- 커스텀 장애물(책장 구조물) 로드 시작 -->
      <name>office_bookshelf</name>                   <!-- 가상 공간 내 개체 고유 이름을 'office_bookshelf'로 지정 -->
      <uri>model://bookshelf</uri>                    <!-- 3D 책장 mesh 모델 파일의 경로 지정 -->
      <pose>2.0 1.5 0.0 0 0 0</pose>                  <!-- 가상 공간 배치 좌표 지정 (x=2.0m, y=1.5m, z=0.0m, R/P/Y=0) -->
    </include>                                        <!-- 장애물 로드 종료 -->

  </world>                                            <!-- 월드 정의 종료 -->
</sdf>                                                <!-- SDF 문서 종료 -->
💻 gazebo_world.launch.py (Gazebo World 실행 파이썬 런치 파일)
import os                                            # 운영체제 파일 및 디렉토리 경로 처리를 위한 os 모듈 임포트
from ament_index_python.packages import get_package_share_directory # ROS 2 패키지의 설치 경로를 찾기 위한 함수 임포트
from launch import LaunchDescription                # Launch 실행 목록을 구성하는 기본 LaunchDescription 클래스 임포트
from launch.actions import IncludeLaunchDescription # 다른 외부 launch 파일을 포함시켜 함께 실행하는 액션 클래스 임포트
from launch.launch_description_sources import PythonLaunchDescriptionSource # 파이썬 형태의 launch 소스를 지정하는 모듈 임포트

def generate_launch_description():                   # ROS 2 Launch 시스템이 호출하는 필수 엔트리 포인트 함수 정의

    pkg_gazebo_ros = get_package_share_directory('gazebo_ros') # ROS 2-Gazebo 연동 공식 패키지의 share 디렉토리 경로 획득
    pkg_sim_world = get_package_share_directory('my_sim_package') # 프로젝트 커스텀 시뮬레이션 패키지의 share 경로 획득
    
    world_path = os.path.join(pkg_sim_world, 'worlds', 'my_custom_world.world') # 실행할 .world 파일의 절대 경로 조합

    gzserver_cmd = IncludeLaunchDescription(          # Gazebo 백그라운드 서버(gzserver)를 실행할 액션 구문 작성
        PythonLaunchDescriptionSource(                # gazebo_ros 패키지 내부의 gzserver.launch.py 파일 경로 지정
            os.path.join(pkg_gazebo_ros, 'launch', 'gzserver.launch.py')
        ),
        launch_arguments={'world': world_path}.items() # 생성한 커스텀 .world 파일 경로를 gzserver 실행 인자로 전달
    )

    gzclient_cmd = IncludeLaunchDescription(          # Gazebo 3D 그래픽 화면(gzclient GUI)을 실행할 액션 구문 작성
        PythonLaunchDescriptionSource(                # gazebo_ros 패키지 내부의 gzclient.launch.py 파일 경로 지정
            os.path.join(pkg_gazebo_ros, 'launch', 'gzclient.launch.py')
        )
    )

    return LaunchDescription([                        # 구성된 Gazebo Server 및 Client 실행 액션 배열을 LaunchDescription 객체로 반환
        gzserver_cmd,                                 # 1. 물리 연산 서버 실행
        gzclient_cmd                                  # 2. 3D GUI 화면 실행
    ])
