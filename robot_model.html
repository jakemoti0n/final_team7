1-2. 로봇 형상 및 물리 모델링 (URDF / Xacro)

← 메인 목록

URDF (Unified Robot Description Format) 및 Xacro는 로봇을 하나의 **부품 계층 트리(Link-Joint Tree)**로 표현합니다. 기준이 되는 차체(`base_link`)를 중심으로 관절(`Joint`)을 매개체 삼아 좌/우 바퀴 및 LiDAR 센서 등의 강체(`Link`)를 조립하고, 각각의 질량·관성 및 마찰 계수를 부여하여 Gazebo 물리 시뮬레이션 및 RViz2 3D 좌표계(`TF`)와 연동합니다.

▲ [그림 1-2] 로봇 3D 형상 요소(좌) 및 Xacro로 구성된 URDF 부모-자식(Link-Joint) 계층 트리 구조(우)
주요 역할 및 특징
  • Link & Joint 트리 구조: `base_link` 중심의 부모-자식 상속 구조로 바퀴 및 센서의 상대적 3D 좌표축 설정
  • 물리 특성 부여 (Inertial & Collision): Gazebo 시뮬레이션용 질량($kg$), 관성 모멘트 Tensor, 충돌 영역(Collision) 정의
  • Xacro 모듈화: 반복되는 바퀴 및 센서 설정을 속성(Property) 및 매크로(Macro)화하여 코드 재사용률 증대
  • TF 3D 좌표계 발행: robot_state_publisher 노드가 로봇 각 부위의 상대 3D 위치 정보를 /tf 토픽으로 실시간 계산
URDF / Xacro 주요 요소 사양
요소 이름 SDF/URDF 코드 태그 기능 및 역할
<link> <visual>, <collision>, <inertial> 로봇의 외형 그래픽, 물리 충돌 범위, 질량 및 관성 모멘트를 포함하는 단위 강체
<joint> type="continuous" / "fixed" 두 Link 사이를 연결하는 관절 (바퀴 회전축, 센서 고정대 등)
<xacro:macro> <xacro:macro name="wheel"...> 좌/우 바퀴 및 다중 센서와 같은 중복 요소를 함수처럼 매크로로 재사용
gazebo plugin libgazebo_ros_diff_drive.so Gazebo 내에서 URDF 바퀴 모터를 제어하는 휠 드라이브 바퀴 제어 플러그인
설정 및 코드 예시
📄 robot.urdf.xacro (로봇 차체 및 바퀴 정의 Xacro 파일)
<?xml version="1.0"?>                                 <!-- XML 문서 형식을 1.0 표준으로 선언 -->
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="my_robot"> <!-- Xacro 네임스페이스 등록 및 로봇 이름을 'my_robot'으로 설정 -->

  <!-- ================= 변수 및 상수 정의 ================= -->
  <xacro:property name="wheel_radius" value="0.1"/>  <!-- 바퀴 반지름 변수를 0.1m (10cm)로 정의 -->
  <xacro:property name="wheel_width" value="0.05"/>   <!-- 바퀴 두께 변수를 0.05m (5cm)로 정의 -->

  <!-- ================= 로봇 중심 차체 (Base Link) ================= -->
  <link name="base_link">                             <!-- 로봇의 기준이 되는 최상위 강체(Link) 정의 시작 -->
    <visual>                                          <!-- RViz2/Gazebo에 보일 시각적 메쉬/도형 정의 -->
      <geometry>                                      <!-- 차체 기하학적 형상 설정 -->
        <box size="0.5 0.3 0.15"/>                    <!-- 직육면체 차체 (길이 0.5m, 너비 0.3m, 높이 0.15m) -->
      </geometry>                                     <!-- 형상 설정 종료 -->
      <material name="green">                          <!-- 시각화 색상 지정 -->
        <color rgba="0.18 0.49 0.19 1.0"/>             <!-- RGBA 그린 컬러 적용 -->
      </material>                                     <!-- 재질 설정 종료 -->
    </visual>                                         <!-- 시각적 형상 정의 종료 -->

    <collision>                                       <!-- Gazebo 물리 충돌 연산용 범위 정의 -->
      <geometry>                                      <!-- 충돌 영역 형상 지정 -->
        <box size="0.5 0.3 0.15"/>                    <!-- Visual과 동일한 크기의 직육면체 충돌 영역 적용 -->
      </geometry>                                     <!-- 충돌 형상 종료 -->
    </collision>                                      <!-- 충돌 정의 종료 -->

    <inertial>                                        <!-- 물리 시뮬레이션용 질량 및 관성 모멘트 정의 -->
      <mass value="5.0"/>                             <!-- 차체 무게를 5.0kg으로 설정 -->
      <inertia ixx="0.04" ixy="0" ixz="0" iyy="0.11" iyz="0" izz="0.13"/> <!-- 직육면체 계산식 기반 관성 텐서 적용 -->
    </inertial>                                       <!-- 관성 정의 종료 -->
  </link>                                             <!-- Base Link 정의 종료 -->

  <!-- ================= 바퀴 생성용 Xacro 매크로 ================= -->
  <xacro:macro name="wheel" params="prefix y_reflect"> <!-- 좌/우 바퀴 재사용을 위한 매크로 함수 정의 -->
    <link name="${prefix}_wheel">                     <!-- 바퀴 Link 생성 (예: left_wheel, right_wheel) -->
      <visual>                                        <!-- 바퀴 시각화 설정 -->
        <geometry>                                    <!-- 바퀴 형상 설정 -->
          <cylinder radius="${wheel_radius}" length="${wheel_width}"/> <!-- 상수로 선언한 반지름/두께로 원기둥 생성 -->
        </geometry>                                   <!-- 형상 종료 -->
      </visual>                                       <!-- 시각화 종료 -->
    </link>                                           <!-- 바퀴 Link 종료 -->

    <joint name="${prefix}_wheel_joint" type="continuous"> <!-- 무한 회전 가능한 continuous 관절(Joint) 생성 -->
      <parent link="base_link"/>                       <!-- 부모 노드를 차체(base_link)로 지정 -->
      <child link="${prefix}_wheel"/>                  <!-- 자식 노드를 해당 바퀴 Link로 연결 -->
      <origin xyz="0.0 ${y_reflect * 0.18} 0.0" rpy="-1.57 0 0"/> <!-- 좌/우 Y축 오프셋 위치 및 90도 회전 수평 배치 -->
      <axis xyz="0 0 1"/>                              <!-- 회전 중심축을 Z축으로 지정 -->
    </joint>                                          <!-- Joint 정의 종료 -->
  </xacro:macro>                                      <!-- 매크로 정의 종료 -->

  <!-- ================= 매크로 호출로 좌/우 바퀴 생성 ================= -->
  <xacro:wheel prefix="left" y_reflect="1" />         <!-- 왼쪽 바퀴 생성 (y_reflect=+1) -->
  <xacro:wheel prefix="right" y_reflect="-1" />       <!-- 오른쪽 바퀴 생성 (y_reflect=-1) -->

</robot>                                              <!-- 로봇 정의 종료 -->
💻 rsp_launch.py (robot_state_publisher 실행 런치 파일)
import os                                            # OS 파일 경로 조합을 위한 패키지 임포트
import xacro                                         # Xacro 파일을 XML URDF 코드로 변환해주는 파이썬 라이브러리 임포트
from ament_index_python.packages import get_package_share_directory # 패키지 share 경로 획득 함수
from launch import LaunchDescription                # Launch 실행 메인 객체 클래스 임포트
from launch_ros.actions import Node                  # ROS 2 노드를 실행하기 위한 액션 클래스 임포트

def generate_launch_description():                   # ROS 2 Launch 진입점 함수 정의

    pkg_path = get_package_share_directory('my_robot_description') # 로봇 모델 패키지의 경로 가져오기
    xacro_file = os.path.join(pkg_path, 'urdf', 'robot.urdf.xacro') # xacro 파일의 절대 경로 결합
    
    # Xacro 파싱 및 URDF XML 텍스트 추출
    doc = xacro.parse(open(xacro_file))               # xacro 파일 읽기 및 파싱 객체 생성
    xacro.process_doc(doc)                           # 매크로 및 변수 연산을 처리하여 완벽한 URDF XML로 변환
    robot_description = {'robot_description': doc.toxml()} # 노드 파라미터로 전달할 XML 텍스트 딕셔너리 생성

    # robot_state_publisher 노드 설정
    node_robot_state_publisher = Node(               # ROS 2 노드 구동 객체 생성
        package='robot_state_publisher',             # 실행할 ROS 2 패키지명 지정
        executable='robot_state_publisher',         # 실행할 바이너리 노드명 지정
        output='screen',                             # 터미널 창에 로그 출력 설정
        parameters=[robot_description]               # 로봇 URDF XML 문자열을 파라미터로 주입
    )

    return LaunchDescription([                        # 실행할 노드 배열 반환
        node_robot_state_publisher                   # 1. 로봇 상태 및 TF 좌표 발행 노드 실행
    ])
