1-4. 텔레옵 주행 및 휠 제어 (Diff Drive Controller)

← 메인 목록

Teleop 노드(키보드/조이스틱)로부터 발행되는 속도 명령(geometry_msgs/Twist)을 수신하여 차동 구동(Differential Drive) 로봇의 양쪽 바퀴 속도로 변환 제어합니다. Gazebo ROS Diff Drive 플러그인(`libgazebo_ros_diff_drive.so`)을 통해 실제 바퀴 회전을 모사하고, 엔코더 기반의 **Odometry(주행 거리 오차 계산값)** 데이터 및 **TF 트랜스폼(`odom` ➔ `base_footprint`)**을 실시간으로 계산하여 발행합니다.

▲ [그림 1-4 고도화] Teleop 명령 ➔ 좌/우 바퀴 모터 물리 구동 ➔ 엔코더 기반 2D 좌표 오도메트리 및 TF 피드백 흐름 일러스트
주요 역할 및 특징
  • 역운동학(Inverse Kinematics) 연산: 입력된 속도 명령($v, \omega$)을 좌/우 바퀴의 물리적 회전 속도로 정확히 나누어 구동 관절에 전달
  • 바퀴 모터 물리 시뮬레이션: Gazebo 환경에서 실제 모터의 토크 한계와 마찰력(Slip)을 고려해 바퀴 회전 제어
  • 순운동학(Forward Kinematics) 기반 Odometry: 바퀴 회전량(엔코더)을 실시간으로 추적하여 로봇의 2D 평면상 위치 $(x, y, \theta)$ 계산 및 `/odom` 토픽 발행
  • TF 좌표계 브로드캐스팅: 지도 제작(SLAM)과 자율주행(Nav2)의 기준이 되는 `odom` ➔ `base_footprint` 좌표 변환 프레임 실시간 제공
제어 토픽 및 TF 명세
구분 토픽 / TF 이름 메시지 타입 설명
입력 토픽 /cmd_vel geometry_msgs/msg/Twist 로봇의 목표 선속도(m/s) 및 각속도(rad/s) 명령
출력 토픽 /odom nav_msgs/msg/Odometry 엔코더 추정 로봇 위치, 방향, 이동 속도 피드백
TF 변환 odom ➔ base_footprint tf2_msgs/msg/TFMessage 로봇 시작점을 기준 좌표계로 한 이동 변환 프레임

💻 teleop_keyboard_node.py (ROS 2 속도 명령 발행 키보드 수동 노드)
import rclpy                                          # ROS 2 파이썬 Client 라이브러리 임포트
from rclpy.node import Node                             # ROS 2 Node 기본 클래스 임포트
from geometry_msgs.msg import Twist                    # 속도 제어 명령 메시지 타입(Twist) 임포트

class CustomTeleopNode(Node):                         # CustomTeleopNode 클래스 선언
    def __init__(self):
        super().__init__('custom_teleop_node')        # 노드 이름을 'custom_teleop_node'로 초기화
        
        # /cmd_vel 토픽 발행자(Publisher) 생성 (QoS Depth: 10)
        self.publisher_ = self.create_publisher(
            Twist,                                    # 발행할 메시지 타입 (Twist)
            '/cmd_vel',                               # 발행할 토픽 이름 (/cmd_vel)
            10                                        # 통신 버퍼 크기
        )
        self.get_logger().info('Teleop 키보드 수동 제어 노드가 시작되었습니다.') # 안내 로그 출력

    def send_velocity_command(self, linear_x, angular_z): # 속도 명령 전송 메서드
        msg = Twist()                                 # Twist 메시지 객체 생성
        msg.linear.x = float(linear_x)                # 전진/후진 직진 선속도 설정 (m/s)
        msg.angular.z = float(angular_z)              # 좌/우 회전 각속도 설정 (rad/s)
        
        self.publisher_.publish(msg)                  # /cmd_vel 토픽으로 메시지 발행
        self.get_logger().info(f'[cmd_vel 발행] 선속도: {linear_x} m/s, 각속도: {angular_z} rad/s')

def main(args=None):                                  # 메인 함수
    rclpy.init(args=args)                             # ROS 2 통신 초기화
    node = CustomTeleopNode()                         # 노드 객체 생성
    
    try:
        # 직진 테스트 (0.2 m/s 선속도 전송)
        node.send_velocity_command(0.2, 0.0)
    except KeyboardInterrupt:
        pass                                         # Ctrl+C 예외 처리
    finally:
        node.send_velocity_command(0.0, 0.0)          # 종료 시 로봇 정지 명령 발행
        node.destroy_node()                          # 노드 자원 해제
        rclpy.shutdown()                             # ROS 2 파이썬 통신 종료

if __name__ == '__main__':
    main()                                           # 메인 함수 실행
