5. Waypoint Follower Server

← 메인 목록

Waypoint Follower Server는 여러 개의 목적지 좌표(경유지 리스트)를 순서대로 방문하도록 제어하는 Nav2 서버입니다. 단일 목표 지점으로 이동하는 NavigateToPose와 달리, 순찰/배달 업무처럼 **A ➔ B ➔ C ➔ D 지점을 순차적으로 경유**해야 하는 자율주행 미션에 사용됩니다. 각 경유지에 도달했을 때 수행할 추가 작업(예: 사진 촬영, 택배 하차 대기, 멈춤 등)은 Task Task / Waypoint Task 플러그인을 통해 연동할 수 있습니다.

▲ [Waypoint Follower] 순차적 경유지 순회 및 지점별 Task(대기, 카메라 촬영 등) 수행 흐름
주요 역할 및 특징
  • 다중 목적지 순회: 경유지 리스트(List[PoseStamped])를 전달받아 순서대로 내비게이션 수행
  • Waypoint Task 연동: 특정 경유지 도착 시 '대기', '센서 측정', '승강기 호출' 등의 추가 작업 실행 가능
  • 에러 핸들링 옵션: 특정 경유지 이동 실패 시 다음 경유지로 건너뛸지(Skip), 전체 미션을 중단할지 설정 가능
  • Loop/순찰 기능: 지정된 경유지 리스트를 무한 반복 순찰하도록 구현할 수 있음
주요 Waypoint Task 플러그인 종류
플러그인 이름 지정 클래스 동작 설명 및 활용 목적
WaitAtWaypoint nav2_waypoint_follower::WaitAtWaypoint 경유지에 도착했을 때 지정된 시간(초) 동안 제자리에 정지 후 다음 목적지로 이동
PhotoAtWaypoint nav2_waypoint_follower::PhotoAtWaypoint 경유지 도착 시 카메라/센서 데이터를 파일로 저장하거나 서버로 전달한 후 이동
InputAtWaypoint nav2_waypoint_follower::InputAtWaypoint 사용자의 외부 입력 신호(버튼 클릭, API 요청 등)가 들어올 때까지 대기 후 이동
설정 및 코드 예시
📄 nav2_params.yaml (Waypoint Follower 설정 파라미터)
waypoint_follower:
  ros__parameters:
    loop_rate: 20                           # 경유지 상태 체크 주기 (Hz)
    stop_on_failure: true                   # 경유지 하나라도 이동 실패 시 전체 미션 중단 여부 (false 시 다음 WP로 건너뜀)
    waypoint_task_executor_plugin: "wait_at_waypoint" # 도착 시 실행할 Task 플러그인 지정

    # --- 도착 후 대기(WaitAtWaypoint) 플러그인 세부 설정 ---
    wait_at_waypoint:
      plugin: "nav2_waypoint_follower::WaitAtWaypoint" # 대기 기능 수행 플러그인 클래스
      enabled: true                          # 플러그인 활성화 여부
      waypoint_pause_duration: 5000          # 경유지 도착 후 정지해 있을 시간 (밀리초 단위, 5000ms = 5초)
💻 Python rclpy Action Client (FollowWaypoints 호출 예시)
import rclpy                                      # ROS 2 Python 클라이언트 라이브러리 임포트
from rclpy.node import Node                       # ROS 2 노드 클래스 임포트
from rclpy.action import ActionClient             # ROS 2 Action Client 모듈 임포트
from nav2_msgs.action import FollowWaypoints       # Waypoint Follower 액션 메시지 타입 임포트
from geometry_msgs.msg import PoseStamped         # 좌표 생성을 위한 PoseStamped 메시지 임포트

class WaypointClient(Node):
    def __init__(self):
        super().__init__('waypoint_action_client') # 'waypoint_action_client' 이름으로 노드 초기화
        # Waypoint Follower Server의 "follow_waypoints" 액션 서버와 통신할 Client 생성
        self._action_client = ActionClient(self, FollowWaypoints, 'follow_waypoints')

    def send_waypoints(self):
        # 1. FollowWaypoints 목표 메시지(Goal) 객체 생성
        goal_msg = FollowWaypoints.Goal()

        # 2. 첫 번째 경유지(WP 1) 좌표 설정
        wp1 = PoseStamped()
        wp1.header.frame_id = 'map'               # 기준 좌표계 'map'
        wp1.header.stamp = self.get_clock().now().to_msg()
        wp1.pose.position.x = 2.0                 # WP 1 X 좌표 (m)
        wp1.pose.position.y = 1.0                 # WP 1 Y 좌표 (m)

        # 3. 두 번째 경유지(WP 2) 좌표 설정
        wp2 = PoseStamped()
        wp2.header.frame_id = 'map'               # 기준 좌표계 'map'
        wp2.header.stamp = self.get_clock().now().to_msg()
        wp2.pose.position.x = 4.5                 # WP 2 X 좌표 (m)
        wp2.pose.position.y = 3.0                 # WP 2 Y 좌표 (m)

        # 4. 경유지 리스트에 담아서 액션 메시지에 할당
        goal_msg.poses = [wp1, wp2]

        # 5. 액션 서버 준비 상태 확인 및 대기
        self._action_client.wait_for_server()

        # 6. Waypoint Follower Server에 순차 이동 비동기 요청 전송
        return self._action_client.send_goal_async(goal_msg)

def main(args=None):
    rclpy.init(args=args)                         # ROS 2 Python 통신 시스템 초기화
    wp_node = WaypointClient()                    # 경유지 순회 요청 노드 인스턴스 생성
    wp_node.send_waypoints()                      # 지정된 WP 1, WP 2 위치 순회 시작
    rclpy.spin(wp_node)                           # 콜백 이벤트 대기 루프 실행

if __name__ == '__main__':
    main()
