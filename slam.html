2-1. SLAM (Cartographer / Slam Toolbox)

← 메인 목록

SLAM (Simultaneous Localization and Mapping)은 로봇이 미지의 공간에서 센서(LiDAR, 오도메트리 등)를 활용해 자신의 위치 추정(Localization)과 주변 환경의 지도 작성(Mapping)을 동시에 수행하는 기술입니다. ROS 2 환경에서는 구글이 개발한 그래프 기반 최적화 방식의 Cartographer와 실시간 맵핑 및 루프 클로저 성능이 뛰어난 Slam Toolbox가 대표적으로 활용됩니다.

▲ [그림 2-1] 센서 데이터 입력 ➔ Cartographer / Slam Toolbox 엔진 연산 ➔ Occupancy Grid Map 및 TF 발행 흐름도
SLAM 주요 프레임워크 비교
  • Cartographer: 구글에서 개발한 실시간 동시 위치 추정 및 맵핑 알고리즘으로, 여러 센서 데이터를 받아 서브맵(Submap)을 만들고 백엔드 포즈 그래프 최적화로 정밀한 지도를 생성합니다.
  • Slam Toolbox: ROS 2 환경에서 널리 쓰이는 슬램 솔루션으로, 특히 수명이 긴 맵 관리(Lifelong Mapping)와 대규모 환경에서의 빠른 루프 클로저 및 지도 병합 기능이 매우 강력합니다.
  • Occupancy Grid Map (/map): 장애물이 있는 영역(검은색), 빈 공간(흰색), 미탐색 영역(회색)으로 구분된 2D 격자 지도를 생성하여 내비게이션 시스템의 기본 바탕이 됩니다.
  • TF 퍼블리셔: 글로벌 좌표계인 map과 로봇 오도메트리 좌표계인 odom 사이의 오차를 보정하여 정확한 위치 변환 정보를 제공합니다.
Cartographer vs Slam Toolbox 비교 명세
구분 Google Cartographer Slam Toolbox
개발 주체 Google (오픈소스) Steven Macenski (Open Navigation)
핵심 방식 서브맵 기반 스캔 매칭 & 포즈 그래프 최적화 고성능 스캔 매칭, 직관적인 노드 그래프 관리
ROS 2 지원 cartographer_ros 패키지 연동 slam_toolbox 공식 패키지 제공
주요 특징 노이즈에 강하고 정밀한 궤적 추정 가능 설정이 비교적 간단하고 지도 수정(Lifelong) 및 저장/로드 기능 우수
설정 및 코드 예시
📄 slam_launch.py (ROS 2 Slam Toolbox 실행 런치 파일 템플릿)
import os
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from ament_index_python.packages import get_package_share_directory

def generate_launch_description():
    # 패키지 경로 및 설정 파일 지정
    use_sim_time = LaunchConfiguration('use_sim_time', default='true')
    
    # Slam Toolbox 노드 실행 설정
    slam_toolbox_node = Node(
        package='slam_toolbox',
        executable='async_slam_toolbox_node',
        name='slam_toolbox',
        output='screen',
        parameters=[{
            'use_sim_time': use_sim_time,           # 시뮬레이션 시간(Gazebo 등) 사용 여부
            'resolution': 0.05,                     # 지도 해상도 5cm 설정
            'max_laser_range': 25.0,                # 라이다 최대 유효 거리 센싱 설정
            'minimum_travel_distance': 0.2,         # 로봇이 일정 거리 이동 시 스캔 갱신
            'minimum_travel_heading': 0.2,          # 로봇 회전 각도 변화 시 스캔 갱신
        }]
    )

    return LaunchDescription([
        DeclareLaunchArgument(
            'use_sim_time',
            default_value='true',
            description='Use simulation (Gazebo) clock if true'
        ),
        slam_toolbox_node
    ])
