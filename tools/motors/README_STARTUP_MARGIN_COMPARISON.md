# 저속 기동 여유 비교: 명시적 15% 상한

이 변경은 앞선 12.5% 상한에서 나타난 작은 카운트 변화와 출발 지연을 비교하기 위한 제한된 시험용이다. 소프트웨어가 허용하는 절대 duty 상한을 4095에서 4915(약 15%)로 확장한다. 모터 정격이나 부하 조건에 적합하다는 검증을 뜻하지 않으며, 원인이나 개선 효과도 실제 시험 전에는 확정하지 않는다.

기본 `max_duty_raw=3276`(약 10%)은 그대로다. 이전 `max_duty_raw=4095` 선택도 그대로 제한된다. 4915는 실행 전에 명시적으로 선택해야 하며 ROS 파라미터는 실행 중 변경할 수 없다. PI 결과, 패킷 생성, 직렬 write 및 raw exchange가 각각 선택된 세션 상한을 검사한다. 어떤 선택에서도 4916 이상은 거부한다.

비교 계획은 같은 목표 속도 0.02m/s, `kp=0.06`, `ki=0.20`, `velocity_window_s=0.10`, `feedforward_gain=0.3375`를 유지한 전진 최대 3초와 별도 세션의 후진 최대 3초다. 전진 종료·정지 확인 후 후진하며, 명령 전에 사용자에게 알린다. 기존 5초 절대 시간 제한, 목표 각속도 0.4rad/s 제한, 출력 변화율 0.15/s, 보고 전류 3A 검사, 속도·회전량/1500카운트·방향·통신 시간 초과·정지 검사는 변경하지 않는다. 기동 보상은 ramped target 비례 항이며 고정 최소 출력이 아니다.

기존 평지 앞뒤 빈 경로, 중앙에 고정된 배터리, 차단 담당자와 주전원 차단 장치를 유지한다. ROS 명령 한 개로 끝나는 유한 시험이며 자동 재시험이나 추가 상한 확대를 하지 않는다. 일반 `/cmd_vel` 중단 감지, 연속 주행, Nav2, 보드 PID/QPPS·NVM 쓰기는 이 변경에 포함하지 않는다.

새 summary 및 진단 상태에는 `envelope='duty_ceiling_4915_v1'`를 기록한다. 기존 `controller_model='partial_headroom_feedforward_v2'`와 `velocity_estimator='exact_window_linear_v1'`는 바뀌지 않는다. 분석기는 새 envelope가 정확히 일치할 때만 4915까지 허용하고, 태그가 없는 이전 자료는 기존 4095 경계를 유지해야 한다. 알 수 없는 태그는 거부한다. 3초 기록은 종전 장시간 속도 추종 평가를 자동으로 통과한 것으로 취급하지 않는다.

검사는 기본 10%·선택 12.5%에서 높은 raw 패킷 거부, 명시적 4915의 양방향/zero, 4916 거부, 만료 세션 거부, FF 활성 상태의 선택 상한·출력 변화율·정지 초기화, ROS 선택 상한 전달·불변성·envelope 기록을 확인한다. 이 문서는 실제 시험 결과가 아니라 변경 범위와 검증 조건을 기록한다.
