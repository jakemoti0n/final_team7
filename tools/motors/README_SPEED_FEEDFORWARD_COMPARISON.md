# 램프 목표에 비례하는 feedforward 비교

새 model은 `partial_headroom_feedforward_v2`다. readonly `feedforward_gain`의 기본값은0.0(비활성), 허용 범위는 유한수0~0.375다. 기존 기본 gain·창·출력 상한과 단일 명령/최대5초 실행은 유지한다. 이전 `partial_headroom_v1` 소스·기록은 별도 보존한다.

`FF = feedforward_gain × ramped_target_rad_s`를 계산하고 기존P·I와 더한 다음 같은 출력 방향·cap·slew 범위를 적용한다. 부분 적분은 경계에서 FF+P를 뺀 남은 여유만 허용한다. FF는 목표 방향을 따르고, 적분은 overspeed 때 FF를 상쇄하도록 반대 부호가 될 수 있다. 최종 모터 출력은 목표 반대 방향으로 나가지 않는다.

이번 후보 gain0.3375에서 목표0.2666667rad/s의 FF는0.09(9% duty 분율)다. 이는 고정 최소 출력이나 기동 kick가 아니다. 목표 램프를 따르며 P+I가 출력을0까지 줄일 수 있다. zero 명령에서는FF·적분·출력·방향 상태가 완전히0으로 reset된다. `PIResult.feedforward_output`을 별도 기록한다.

기존 출력 상한4095(약12.5%)·출력 slew0.15/s·목표0.02m/s와 동일한 종료/통신/표본/전류/카운트 guard를 유지한다. FF=0인 경우 새FF필드를 제외한 v1의 공통 계산은 동일하다. 시험에만 gain0.3375를 명시하고, 명령 전 사용자에게 알리며 한 회차 뒤 결과를 확인한다. 자동 추가 증량·재시도·연속 주행 기능은 없다.

이 변경은 목표 출력을 미리 일부 제공해 적분만으로 기동 출력을 쌓는 시간을 줄이려는 후보다. 마찰·기구·접촉 문제를 해결했다고 가정하지 않으며, 동일한 외부200ms 평가창·원시 순간 속도·현장 움직임·정지 결과로 확인한다. 제어 수학 검사와 실제 주행 성능 검증을 구분한다.
