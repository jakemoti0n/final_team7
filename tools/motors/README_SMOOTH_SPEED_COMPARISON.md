# 저속 속도 추정·PI 부분 적분 비교

기존 한 명령·최대5초 시험에 두 수학적 변경을 적용한다. 새 controller model은 `partial_headroom_v1`, 속도 추정 model은 `exact_window_linear_v1`이며 summary에 기록한다. 모터 전송·출력 상한·표본/이동/전류 guard·zero·종료 경로는 변경하지 않는다.

PI는 한 적분 스텝이 출력 한계를 넘으면 전체 스텝을 버리던 방식에서, 남은 headroom까지의 부분 스텝을 허용하도록 바뀐다. 허용하는 변화는 원래 적분 스텝의 방향과 크기 안에 한정한다. P만으로 한계를 넘었을 때 반대 방향 적분을 강제로 만들어 맞추지 않는다. 상태 진단 `integral_limited`, `integral_partial`을 추가하며 zero는 즉시 출력을0으로 만들고 모든 적분 상태를 지운다. 최소 기동 출력·kick·반대 토크·목표 자동 증가 기능은 추가하지 않는다.

속도는 요청된 시간창의 시작 시각에서 두 누적 count 표본 사이를 선형 보간한 뒤 현재 count와 차분한다. 충분한 표본이 없을 때는 baseline 이후 실제 이용가능 구간을 사용한다. 외삽하지 않으며 실제 센서 시간 해상도가 높아진다는 뜻은 아니다. count/JointState 원시 발행은 그대로이고 제어에 쓰는 속도 추정만 달라진다.

readonly `velocity_window_s`는0.10~0.20초, 기본0.20초다. **기본값도 예전의 약0.20~0.25초 표본 경계 창과 달리 정확한0.20초 경계 보간**을 사용한다. 이전 기록은 예전 계산 모델로 보존·재현해야 한다. 기본 Kp0.10/Ki0.20·duty3276은 유지한다. 비교 시험에만 window0.10, Kp0.06/Ki0.20, 명시적 cap4095를 선택한다. 목표0.02m/s·최대5초·출력 상한 약12.5%는 직전 회차와 같다.

짧은 창은 평균화 지연을 줄이지만 count 양자화에 더 민감하다. P를 줄여 출력 변동을 완화하려는 후보이며, 정지 마찰·하중·기계 간섭이 원인이라면 이 수정으로 해결되지 않을 수 있다. Ki까지 크게 낮추면 적분이 기동 출력에 도달하는 시간이 늘어나 제한된5초 동안 거의 움직이지 않을 수 있어 이번 비교에서는 Ki를 유지한다. 성공을 보장하거나 출력 상한을 더 높이는 변경은 아니다.

신구 성능을 비교할 때는 raw count로 동일한0.20초 평가 창을 따로 재구성한다. 내부 제어 창만0.10초로 바뀐 값을 기존0.20초 평가와 직접 섞어 p95 개선으로 주장하지 않는다. 원시 순간 속도·동일 평가 창·새 내부 제어 속도와 사용자 관찰을 구분한다. 실제 명령 전에 사용자에게 알리고 준비 확인된 한 회차만 실행하며, 결과가 미달해도 자동 증량·재시작하지 않는다.
