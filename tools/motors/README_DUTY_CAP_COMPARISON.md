# 한 회차의 출력 상한 비교

2026-10-30 바닥에서 목표0.02m/s를 유지하면서 약10% duty 상한의 영향을 확인하기 위한 한 회차 비교다. 속도 목표를12.5%로 바꾸는 설정이 아니다.

`speed_bench.launch.py`의 `max_duty_raw` 기본값은3276(약10%)이다. 명시적으로4095(약12.5%)를 지정한 세션에만 높은 상한을 적용한다. 런타임 변경은 허용하지 않는다. 4095보다 큰 값·bool·비정수는 거절한다. PI와 직렬 전송 경계가 같은 세션 상한을 적용하고 기존5초·표본/전류/카운트·정지 조건은 유지한다. 보드 PID/QPPS·NVM은 바꾸지 않는다.

바닥 비교는 담당자와 빈 경로를 확인한 뒤 임시 floor runner로 한 번 실행한다. 목표0.02m/s, 최대5초, Kp0.10/Ki0.20 및 기하·CPR은 그대로다. 성능 미달 시 자동 재시도·추가 증량하지 않는다. 종료 후 실제 PWM·카운트·ROS 속도와 별도2초 관찰을 확인한다. 과거 바퀴를 띄운 시험 기록과 바닥 비교는 누적 보고서의 해당 절에서 구분해 읽는다.

이 파라미터는 일반적인 연속주행·cmd_vel 중단감지·Nav2 통합 기능을 추가하지 않는다. 기본 실행기는 여전히 명시적 enable_output과 새 기록폴더·고정목표를 요구한다. 실행 방법과 제약은 README_SPEED_BENCH.md 및 해당 회차 보고서를 따른다.
