## 결론
- **B(`prune_distance` 2.5)는 사람 있는 조건에서도 A와 같은 안전 성적(충돌 0, 사람 최소 거리 같음, 복구 같음)으로 시간이 22~27 % 준다.** 10-13 충장로 결과와 같은 방향. dev 반영 후보 → 채택 권고
- C는 더 빠르지만(31~33 %) MPPI "모든 후보 궤적이 충돌" 경고가 9번(A 1, B 2)으로 늘고, 상한 0.75는 실물이 평지에서만 내는 0.8 m/s에 붙는다. 전제 2-4(속도 상한은 하드웨어 안)에서 C는 보류
- 손님 앞 사람 최소 0.56~0.58 m는 세 조건 모두 같다. 속도 설정과 무관하게 HumanLayer 치명 반경이 정하는 거리
- 1회씩이라 B·C의 홀 시간 차이(57.5 vs 54.8)는 못 가른다
